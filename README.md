# BTP_Thesis

Bachelor's Thesis Project (BTP) work at **IIT Kharagpur**: **GPU covert channels**, studying covert channels built on NVIDIA GPU TLBs. Consolidated from the original repositories, each keeping its full history.

| Folder | What it is |
|---|---|
| [GPU_CPU_Work](GPU_CPU_Work) | BTP project work |
| [gpu-tlb](gpu-tlb) | GPU TLB experiments (BTP thesis work) |
| [gpu-tlb-covert-channel](gpu-tlb-covert-channel) | Proof of concept of covert channels using NVIDIA GPU TLBs |
| [invalidate-compare](invalidate-compare) | Invalidate-compare experiments (BTP thesis work) |
| [Mastik](Mastik) | Mastik micro-architectural side-channel toolkit, used in the thesis work |

Several of these folders originated as forks of upstream projects and keep their upstream licenses.
