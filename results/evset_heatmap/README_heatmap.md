# LLC Set Heatmap Study

Rows are LLC set IDs. Columns are congruent address order within that set.
Color shows slowdown strength for that address under the targeted GPU attack.

- `heatmap_p99_ratio.png`: stable tail effect per address.
- `heatmap_max_ratio_log.png`: strongest spike effect per address.
- `heatmap_summary.csv`: per-set aggregate stats.
