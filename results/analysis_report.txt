================================================================================
GPU-INDUCED CPU CACHE CONTENTION ATTACK: EXPERIMENTAL RESULTS
================================================================================

OVERVIEW
--------------------------------------------------------------------------------
This experiment demonstrates a cross-component cache contention attack
where GPU processes induce cache thrashing on the CPU's Last Level Cache
(LLC) through Unified Virtual Memory (UVM) access patterns.

EXPERIMENTAL SETUP
--------------------------------------------------------------------------------
- CPU Thread: Measures memory access latency using RDTSC
- GPU Process: Concurrently accesses same memory region via UVM
- Memory: 1 MB array in unified memory, prefetched to CPU
- Measurement: 1000 CPU memory accesses with/without GPU contention

RESULTS
================================================================================

Baseline (No GPU Contention):
----------------------------------------
  mean      :       140.42 cycles
  median    :       137.00 cycles
  std       :        30.74 cycles
  min       :       119.00 cycles
  max       :      1027.00 cycles
  p95       :       155.00 cycles
  p99       :       157.00 cycles

With GPU Contention Attack:
----------------------------------------
  mean      :      9073.94 cycles
  median    :        79.00 cycles
  std       :     97162.72 cycles
  min       :        59.00 cycles
  max       :   1638796.00 cycles
  p95       :       400.40 cycles
  p99       :     63971.75 cycles

Attack Impact:
----------------------------------------
  Mean increase:   64.62x
  Max increase:    1595.71x
  P95 increase:    2.58x
  P99 increase:    407.46x

================================================================================
CONCLUSION
================================================================================
The experiment successfully demonstrates that GPU processes can induce
measurable cache contention on the CPU's LLC through UVM. The dramatic
increase in access latency (up to 734x) provides a clear timing side-
channel that could be exploited to infer victim process memory access
patterns in a heterogeneous computing environment.
